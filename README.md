# TABLICA_FIGITAL

Эфирная турнирная сетка 1920×1080 для vMix, в оформлении чемпионата по фиджитал-спорту.

## Состояние

Репозиторий подготовлен для переноса проекта `phygital-bracket` и публикации на Vercel. Полный импорт исходников и графических ресурсов пока не завершён.

Демонстрационные результаты не являются текущими результатами турнира. Источник: Challonge, турнир `cyr6hff7`. Live-режим требует серверной настройки разрешённого доступа к данным.

Никакие API-ключи и другие секреты не должны попадать в репозиторий. Они настраиваются только в переменных окружения хостинга.
