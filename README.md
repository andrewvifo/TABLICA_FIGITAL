# TABLICA_FIGITAL — публичная сетка Challonge

Версия `public-1.1.0`. Оформление и 38 матчей сохранены из исходной графики.

## Источник

Сервер читает `https://challonge.com/ru/cyr6hff7/module` и безопасно разбирает JSON TournamentStore внутри HTML. Никакие ключи, аккаунты судей, cookies и OAuth не нужны. JavaScript стороннего сайта не исполняется.

Счёт складывается из очков `games` обоих этапов; поле `scores`, означающее число выигранных этапов, намеренно не используется. Победитель берётся из `winner_id`. Проверяются ID турнира 18212239, 38 матчей, 20 команд и все переходы. Ошибочный или неполный ответ не заменяет последний проверенный кадр.

## Выходы

- `/` — эфир, без демо.
- `/operator` — контроль источника и время последнего успешного чтения.
- `/api/bracket` — нормализованные результаты; ожидается `adapterVersion: public-1.1.0`.
- `/?demo=1` — только тест оформления по старому фото, не live.

Настройка vMix: Web Browser 1920 × 1080. По умолчанию проверка каждые 30 секунд, общий короткий кэш снижает число обращений. Серверная переменная `POLL_SECONDS` необязательна; ключи Challonge больше не используются.

## Проверки

`npm test` — тестовые данные, 20 проверок. `npm run verify:live` — настоящий публичный источник, проверка каждой суммы и победителя относительно исходного JSON. Отчёт — `docs/LIVE_PUBLIC_CHECK.json`.

Факт успешной проверки в GitHub не заменяет проверку `/api/bracket` в конкретном Vercel-деплое. Облачный источник может временно ограничить доступ; приложение сообщает об этом, сохраняет последний корректный кадр и снижает частоту повторов.
